# سُفرة – مطعم مصري (نسخة تجريبية)

صفحة منيو وسلة طلبات لمطعم مصري وهمي، مكتوبة بـ HTML و CSS و JavaScript بدون أي مكتبات.

## المميزات
- ٧ أقسام و٤٣ صنف بالأسعار بالجنيه المصري
- سلة تتحفظ في المتصفح
- حساب خدمة ١٢٪ وضريبة ١٤٪ والتوصيل
- تحقق من رقم الموبايل المصري
- واجهة RTL ووضع فاتح وغامق

## التشغيل
افتح ملف `index.html` في المتصفح مباشرة.

## النشر على GitHub Pages
1. ارفع الملفات على مستودع جديد.
2. من **Settings ← Pages** اختار فرع `main` والمجلد `/ (root)`.
3. هيظهر الموقع على `https://USERNAME.github.io/REPO-NAME/`

## تعديل المنيو
الأصناف في مصفوفة `ITEMS` داخل `index.html`، وكل صنف بالشكل ده:
`["القسم", "الاسم", "الوصف", "السعر", "إيموجي", "شارة"]`

> الطلب تجريبي ولا يُرسل لأي جهة.
